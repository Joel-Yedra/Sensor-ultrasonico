# 🚗 Arduino Reverse Alarm System

This project consists of a simple reverse alarm system built using Arduino and an ultrasonic sensor. It was designed to simulate how a car's reverse parking sensor works by detecting how close an object is and activating visual and audible alerts accordingly.

# 🔧 How does it work?

-An ultrasonic sensor measures the distance between itself and a nearby object.
-The shorter the distance, the faster the system responds.
-A red LED and a buzzer are activated to simulate an alarm.
-As the object gets closer, the LED and buzzer blink more rapidly to indicate danger.

# 🧰 Components Used

-Arduino UNO board
-HC-SR04 Ultrasonic sensor
-Red LED
-Buzzer
-220 Ohm resistor
-Jumper wires and breadboard
